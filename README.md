# tonkov.eu — unified site, front end (Bootstrap 5)

Static prototype that merges tonkov.eu, iot.tonkov.eu and gorelki.tonkov.eu into one site.
It is the front end only, prepared for integration with the Yii2 backend.

## Run

```bash
npm install
npm run build      # → dist/   (dist/index.html also opens straight from disk)
npm run dev        # build + watch + http://localhost:4173
npm run images     # re-optimise site_pictures/ after adding or replacing a photo
```

Restart `npm run dev` after changing `build.mjs` — the watcher only reloads views, data and assets.

## Where things are

| Path | What | Yii2 equivalent |
|---|---|---|
| `web/` | css, js, img, fonts, vendor (Bootstrap 5.3, Bootstrap Icons) — self-contained | `@webroot` |
| `views/layouts/main.njk` | page shell: head, navbar, footer | `views/layouts/main.php` |
| `views/site/*` | home, about, contact, order, gallery, privacy, error | `SiteController` views |
| `views/category/*` | `view` = generic category; the others are landings for the four directions | `views/category/view.php` |
| `views/product/view.njk` | one template for every product | `views/product/view.php` |
| `views/autoclave/*` | recipes, step-by-step guide | `views/autoclave/*` |
| `views/cart/index.njk` | cart + order form | `views/cart/index.php` |
| `views/partials/_*.njk` | navbar, footer, product card, breadcrumbs, video, demo chart, CTA | partials / widgets |
| `data/site.json` | contacts, navigation, every text on the home page | params / CMS |
| `data/categories.json` | categories (`parent` = sub-category of) | category table |
| `data/products/*.json` | products, one file per direction | product table |
| `data/recipes.json`, `guide.json`, `faq.json`, `gallery.json` | recipes, autoclave guide, boiler FAQ, gallery | — |
| `data/images.json` | generated by `npm run images` — do not edit | — |
| `site_pictures/` | original photos (never modified) | — |
| `build.mjs` | renders `views/` + `data/` into `dist/` | — |

Templates are Nunjucks (`{% for %}`, `{{ var }}`, `{% include %}`, `{% extends %}`) and translate 1:1 to PHP views.
Each one starts with a comment naming its Yii2 counterpart.

## URLs

Root-relative and the same as on the current sites, so existing routes can stay:

```
/                               /category/<slug>.html      /product/<slug>.html
/autoclave/recipes.html         /autoclave/guide.html      /gallery.html
/contact.html  /about.html      /order.html                /privacy-policy.html
/cart/index.html
```

Wood products keep their old slugs. Every product has its previous address in `oldUrl` (for 301 redirects;
an earlier redirect map is in `~/tonkov-site/REDIRECTS.md`, written before the last category changes).

The build rewrites these URLs to relative ones so `dist/` works from disk or a sub-folder.
`node build.mjs --absolute` keeps them root-relative.

## Integration notes

- **CSS**: `web/css/site.css`, loaded after `bootstrap.min.css`. Plain CSS, no Sass; it themes Bootstrap through
  CSS variables (`:root` block at the top) and overrides `.btn-primary`, `.btn-dark`, `.btn-outline-*`.
- **JS**: `web/js/site.js`, vanilla, needs only `bootstrap.bundle.min.js`. Every feature is switched on by a
  `data-*` attribute, so server-rendered markup behaves the same.
- **Forms** use `yii\bootstrap5\ActiveForm` markup and field names (`ContactForm[name]`, `OrderForm[phone]`).
  They carry `data-demo-form`, which blocks submission and shows a notice — remove it when they post to the
  backend, and add `Html::csrfMetaTags()` to the layout.
- **Cart** is a localStorage prototype (`site.js`, section 8). Keep the markup (`data-cart-add`,
  `data-cart-count`, `data-cart`, `data-cart-body`) and replace that block with calls to the cart controller.
  `<html data-root>` is the base path the script uses to build links.
- **Product with models** (the beehive scale): `variants` in the data render a `<select>`; the chosen option
  sets the price and is required before adding to the cart.
- **Product page blocks** (features, specs, variants, demo chart, videos, documents, related) appear only when
  the product has that data.
- **Videos** are lite embeds: a thumbnail from `web/img/video/<id>.webp`, the YouTube iframe loads on click.

## Editing content

- **Home page texts**: `data/site.json` → `home`. Panel titles can be a list of lines.
- **Home page photo framing**: `home.panels[].position` (CSS `object-position`), plus optional `zoom` and `origin`.
  `topAt` (0–1) puts that height of the photo right under the navbar — the autoclave panel uses it for the manometer.
  The hero photo is anchored near its bottom edge in `site.css` (`.hero__media img`).
- **New product**: add an object to the right file in `data/products/`. Minimum: `slug`, `name`, `category`,
  `price` (`null` → "Цена по запитване"), `cta` (`order` or `inquiry`), `images`.
  Put the photo in `web/img/products/` — a large file and a `-t` thumbnail about 520 px wide.
- **Hide a product**: `"active": false`.
- **Site photos** (heroes, workshop, gallery): replace or add the file in `site_pictures/`, run `npm run images`,
  then reference it by file name without extension.
- **Gallery**: `data/gallery.json`. `more` adds extra small photos to an item.

## Demo chart

`views/partials/_demo-chart.njk` is a placeholder on the monitoring page and on the scale and thermo-rope pages.
Set `chartSrc` (rendered as `data-src`) to a JSON url and it becomes a line chart:

```json
{ "label": "Тегло на кошера", "unit": "кг", "points": [["2026-05-01T06:00", 41.2], ["2026-05-01T07:08", 41.3]] }
```
